## 不應放入的資料

以下類型的文件不得放入 claude-workspace：

| 類型 | 說明 |
|------|------|
| 密碼 / API Key | 包含任何登入憑證、金鑰 |
| 付款資料 | 信用卡號、銀行帳號、交易記錄 |
| 客戶私密資料 | 客戶個人資料、購買紀錄、聯絡方式 |
| 公司機密文件 | 未公開的內部文件、合約、財務資料 |
| 未授權素材 | 版權材料、未取得同意的第三方內容 |
