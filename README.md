# Claude 工作資料夾說明

## 這個資料夾用來做什麼

這個資料夾用來管理社群內容創作、課程筆記整理、文件流程優化。

## 主要材料

可以放入：

- 公開資料
- 課程筆記
- 社群靈感
- 低敏練習材料
- 已確認可以給 AI 處理的文件

不要放入：

- 密碼
- API Key
- 付款資料
- 客戶私密資料
- 公司機密文件
- 未授權素材

## 資料夾分區

- 00_inbox：臨時收集，尚未整理
- 10_reference：長期參考資料
- 20_active：正在處理的任務
- 30_output：整理後成果
- 90_archive：完成任務與舊版本

## 使用原則

1. 任務開始前，先確認材料放在哪裡。
2. Claude 第一次讀取時，只做分析，不修改文件。
3. 需要新增或修改文件時，先列計劃，等我確認。
4. 成果放到 30_output，不覆蓋原始材料。
5. 任務結束後，把臨時材料整理或歸檔。
6. 文件命名請加日期前綴，格式為 `YYYYMMDD-文件名稱.md`（例：`20260825-貼文草稿.md`）。
7. 不確定是否可放入的文件，放入前先用安全檢查提示詞確認，不要直接放入。
8. 根目錄只放工作區規則文件（README.md、CLAUDE.md、CHANGELOG.md）。所有材料一律放入子資料夾。
